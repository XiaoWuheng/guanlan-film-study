# 原创演示素材

本目录为项目自行绘制的图形示意，不含影视作品、私人剧本或真实人物。

- `Guanlan-Demo.mp4`：10 秒、无音轨的五镜头示意片段。
- `demo-project.json`：可恢复的示例项目，包含采样图与人工编写的功能说明。
- `demo-1.png` 至 `demo-5.png`：视频使用的原创图形帧。

使用方式：在工作台展开“备用交接与项目备份”，选择“恢复项目备份”，导入 `demo-project.json`。打开学习报告后选择 `Guanlan-Demo.mp4` 即可同步定位。

示例内容用于演示工具，不是 AI 自动分析效果或真实导演意图的验证。素材采用项目 MIT 许可，可用于测试与文档演示。
