# 常见问题

### 必须安装 Codex 吗？

不必。可以使用兼容的 AI 助手，也可以自行配置视觉模型 API；不连接 AI 时仍可手动观察、记录和整理资料。

### 为什么 AI 分析还要复核？

默认只给模型稀疏采样图与文字，完整动作、声音和未采到的画面不在输入里。拆镜也只是候选结果。工具用分项复核帮助你明确哪些内容真的检查过。

### 字幕就是剧本，为什么还区分？

烧录字幕可以作为字幕剧本和文字依据，但不覆盖全部动作、表演、声音和场面调度。仅凭字幕也不能判断拍摄前剧本有哪些删改。独立剧本需要核对版本。

### 为什么原片有时需要重新选择？

网页不能长期持有任意本机文件访问权限。项目备份保留分析和采样图，不包含原视频。电脑端从公开链接导入的视频保存在本机媒体目录，可以在该设备继续关联；换设备仍需带走原片。

### 可以直接用百度网盘或发行平台链接吗？

电脑端可解析部分公开可取得的单文件视频；登录网盘、付费和受保护内容仍需通过自己的平台权限取得。当前不读取浏览器登录凭据，也不拼接分离的高清音画流。

### 为什么看不到“连接成功”？

工具只有收到真实 MCP 调用后才显示已调用状态。配置写入后通常需要重载工具连接，再要求助手列出项目；只打开工作台不代表助手已经连接。

### API 失败后会重复花钱吗？

已完成批次会保存，继续时跳过完成部分。网络中断或服务商返回异常时仍可能已计费；请结合服务商账单核对。程序不会承诺失败调用免费。

### 报告会自动替我下载原片吗？

Excel 是静态学习文档，不包含原视频，也不自动联网取片。同步播放在工作台使用。

### 在 Excel 改过的笔记会同步回来吗？

不会。项目与学习库分别通过备份迁移；Excel 用于阅读、编辑和分享学习成果。

### 怎样报告问题？

请提供版本、系统、浏览器、操作步骤及脱敏截图。优先附上原创或公开许可的短测试片段，不要在公开 Issue 上传真实密钥、私人剧本或未授权影片。
