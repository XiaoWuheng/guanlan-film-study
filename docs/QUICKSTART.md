# 十分钟开始第一份拉片

## 1. 打开工作台

Windows 用户可从 [v0.5.0 发布页](https://github.com/XiaoWuheng/guanlan-film-study/releases/tag/v0.5.0) 下载免安装包，解压整个文件夹后双击 `启动观澜.vbs`。也可用 Node.js 24+ 从源码运行 `npm start`，或按[构建说明](DEVELOPMENT.md)打包。

从旧版升级时，先备份项目和学习库，再关闭旧工作台。新版启动后可恢复备份并关联原片。

首页点「看一段示例」即可原位播放原创短片、切换镜头和查看拍法。点「进入完整拉片室」会带着当前位置打开逐镜报告。

## 2. 放入视频，选择范围

选择浏览器能解码的视频，建议 MP4/H.264。从 1—3 分钟开始，填写起点、终点和学习重点。Windows 电脑端也可以在链接入口导入公开视频。

填写剧名和集号，后续集数可选择同一剧目。投流素材可通过项目卡片的「＋ 素材」加入。

有独立剧本可粘贴或导入 TXT、MD、SRT、VTT。没有剧本时，视觉模型识别画面下部的烧录字幕作为字幕剧本，并为外语字幕补中文译文。Word 或 PDF 剧本请先转成文字。

## 3. 准备候选镜头，先回看

点击「准备镜头」。打开候选报告，回看原片核对切点。「复核」中的「校正镜头」支持按估算帧率步进、当前位置切镜和合并下一镜。

局部调整只重抽受影响镜头；受影响旧记录保存在调整历史，并自动下载调整前备份。未有后续项目修改时可立即撤销；刷新页面后请使用备份恢复。不要在未核对的候选切点上直接认定准确镜长。

## 4. 选择分析方式

- 有支持本机 MCP 与图片工具返回的助手：按右上角配置连接，要求助手分析当前项目。
- 有视觉模型 API：填写地址、模型名和 Key，核对预计调用量后开始。
- 暂不接 AI：直接写人工观察和学习笔记。

失败或停止后可继续已完成批次。完成的镜头会跳过，待补镜头和全片总结按实际需要处理。AI 结果是草稿。

## 5. 逐镜看，再连起来看

「逐镜学习」中可跳转、回看本镜、慢放，也可以先隐藏讲解，自己判断镜头的作用。分镜时间线可选择场景、镜头、字幕和笔记栏位。播放器的设置里可调音量、速度和双语字幕。「剧情总览」展示开场钩子、情绪节拍、镜头组合和练习。点击字幕列表的铅笔可修订原文、译文或说话者，片段笔记可截取画面并绘制标记。

在「复核」中补充人工观察、修正字段、记录实际听到的声音。切点、字幕、完整动态、原声和拍法解释分别勾选。勾选代表你本人已核对。

## 6. 带走学习成果

- 点「导出 Excel」，选择当前集、指定集数或整剧，得到带逐镜表、采样图和人工记录的 `.xlsx`。
- 点「备份」，迁移剧目资料、分析和笔记。换设备时带上对应原片。
- 将有用拍法“收藏为导演方法”，写清适用条件与边界。
- 在学习库新增自己的方法，或编辑拉片自动整理的方法。「管理分类」可增删、改名和恢复片型与学习主题。
- 选好片型、主题或来源，再点「导出方法论」下载当前结果的 Excel。清空筛选可导出全部方法。
- 「更多」里的学习库备份可迁移已保存的方法、分类、移除记录和参考资料。自动整理的方法随项目备份恢复。

Excel 修改不会自动写回工作台。方法复核后仍须主动选择“用于当前项目”，才会作为后续分析的学习参考。
