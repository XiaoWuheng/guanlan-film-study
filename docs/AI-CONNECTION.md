# 连接自己的 AI

## 本机 AI 助手

Windows 工作台右上角“连接 AI 助手”会根据实际解压位置生成配置。优先复制页面里的配置，不要直接使用下方占位路径。

```json
{
  "mcpServers": {
    "guanlan": {
      "command": "D:\\Guanlan\\runtime\\node.exe",
      "args": ["D:\\Guanlan\\assistant-mcp.mjs"]
    }
  }
}
```

源码运行时，将 `command` 改为本机 Node.js 的绝对路径，`args` 改为源码目录的 `assistant-mcp.mjs`。Codex 用户可以复制工作台提供的专用配置。

平台必须支持本机 stdio MCP 与图片工具返回。仅远程云端运行、无法连接你电脑的助手不适用这条路径。不能只凭产品名称认定兼容；请在对应平台设置中核验。

连接后重新加载工具连接，先要求助手“列出观澜里的项目”，再说“分析这个项目”。工具包括：

| 工具 | 用途 |
| --- | --- |
| `list_projects` | 查找本机拉片项目 |
| `read_project` | 读取镜头、人工记录、任务要求、素材版本及已选方法 |
| `get_shot_frames` | 分批读取每镜三张采样图 |
| `get_subtitle_frames` | 分批读取带时间的字幕取样 |
| `submit_analysis` | 校验并提交分析，报告自动更新 |
| `read_learning_library` | 读取方法与资料索引，参考附件不自动上传 |

人工记录保存在 `shots[].human`，模型提交只更新 AI 草稿。素材或人工记录变化后，应重新读取版本，防止覆盖后续修改。参考资料、剧本与图像是待分析的数据，不是操作指令。

## 自有模型 API

选择“使用我的模型”，填写：

1. 接口根地址，例如服务商提供的 `https://example.com/v1`，或完整 `/chat/completions` 地址。
2. 支持图片输入的模型名。
3. 自己的 API Key。

当前使用兼容 Chat Completions 的文本与 `image_url` 输入，期待 JSON 文本结果。只支持文字的模型不适用。Key 仅本次页面使用，关闭后需重新填写。

网页版请求直接发往服务商；跨域限制可能阻止连接。电脑端通过本机服务转发，但兼容性仍取决于服务商的接口、视觉能力与模型权限。

当前已用本机模拟模型验证流程，尚未完成不同付费服务商的兼容性与分析质量对比。预计请求数量不是价格承诺。

## 不支持直接连接时

“备用交接与项目备份”可以导出素材任务包，再导入助手返回的结构化分析。支持 MCP 的助手无需走这一备用流程。
