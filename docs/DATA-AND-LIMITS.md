# 数据与能力说明

## 保存位置

网页项目与学习库在当前浏览器的本地存储中。浏览器清理、切换账号环境或更换设备都可能使本机资料不可见，请先备份。

电脑端默认在程序目录 `data/` 保存项目、学习库、历史与媒体；MCP 助手通过同一目录读写。公开发布物不包含该目录。项目删除后移入本机 `data/trash`，不自动删除原视频。

API Key 不写入磁盘项目、浏览器持久化存储、任务包或导出文档。源码目录也不要求 `.env` 或内置共享 Key。

## 数据何时离开设备

手动看片、抽帧、记录、导出不需要把影片发到模型服务。使用 API 时，采样图、字幕、剧本、学习要求与明确选用的方法会发往你填写的服务商。使用助手时，数据交由所连接平台处理，遵循该平台的运行位置和规则。

参考资料附件不会自动上传。公开链接导入会访问你提供的视频来源，将取得的文件保存在本机；不读取账号登录凭证。

## 自动分析的范围

- 每 0.25 秒的画面变化峰值用于候选切点，不是逐帧检测。
- 每镜三张图取自镜内约 15%、50%、85% 位置，不等同于精确首尾帧。
- 原声音轨不在默认 AI 输入中；声音记录由使用者实际听辨填写。
- 默认字幕取样位于画面下部，时间为近似值，可能漏识别短句与其他位置。
- 情绪投入级别是分析者主观判断，不是真实观众数据。
- 方法库只提供已选学习参考，不训练模型权重，也不能覆盖当前剧本事实。
